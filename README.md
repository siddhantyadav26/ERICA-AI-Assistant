# 🤖 ERICA — AI Voice Assistant

> A Python-based voice assistant that uses speech recognition and text-to-speech to perform everyday tasks.

## ✨ Features

- 🎙️ Speech recognition
- 🔊 Text-to-speech responses
- 🌐 Open websites using voice commands
- 🔎 Search Wikipedia using voice commands
- 🤖 Interactive voice-based assistance
- ⚡ Simple and lightweight Python implementation

## 🛠️ Technologies

- Python
- SpeechRecognition
- pyttsx3
- Wikipedia API
- PyAudio
